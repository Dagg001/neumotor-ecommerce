NEUMOTOR - E-COMMERCE DE NEUMÁTICOS

Proyecto final para el Laboratorio de Aplicaciones Web Cliente. 
Neumotor es una Single Page Application (SPA) responsiva que simula una tienda en línea completa para la venta de neumáticos, cumpliendo con todos los requisitos de lógica de negocio, UX/UI, accesibilidad y consumo de datos mediante Fetch.

---------------------------------------------------------
TECNOLOGÍAS UTILIZADAS
---------------------------------------------------------
- HTML5: Estructurado mediante etiquetas semánticas (<header>, <nav>, <main>, <aside>, <section>, <footer>) para garantizar accesibilidad.
- CSS3 & Bootstrap 5.3: Diseño 100% responsivo (Mobile First), grillas adaptables y componentes interactivos (Navbar colapsable, Offcanvas para el carrito, Modales).
- JavaScript (ES6+): Manipulación dinámica del DOM, asincronía (async/await) y eventos.
- Local Storage: Persistencia de datos tanto para el inventario (simulación de base de datos) como para el carrito de compras.
- Fetch API: Consumo de datos desde un archivo local (productos.json) simulando la carga de un endpoint externo.
- SweetAlert2: Mejora de la experiencia de usuario (UX) mediante alertas estilizadas y no intrusivas.

---------------------------------------------------------
FUNCIONALIDADES PRINCIPALES (LÓGICA DE NEGOCIO)
---------------------------------------------------------
1. Catálogo Dinámico: Renderizado automático de productos consumidos mediante fetch.
2. Modal de Detalle: Vista rápida del producto con su información completa (precio, cuotas, descuento, descripción y stock disponible) sin recargar la página.
3. Buscador y Filtros Combinados: 
   * Barra de búsqueda en tiempo real (por título, categoría o medida).
   * Filtrado por categoría (Auto, SUV, Camioneta, etc.).
   * Filtrado múltiple por Rodado (Checkbox).
   * Ordenamiento dinámico (Precio ascendente/descendente y alfabético).
4. Carrito de Compras (Sidebar / Offcanvas):
   * Visualización del total de productos en una burbuja (Badge) en la navegación.
   * Modificación de cantidades (botones + y - con deshabilitación dinámica al llegar a 1).
   * Eliminación individual o vaciado completo del carrito.
   * Actualización instantánea del subtotal y el precio final.
5. Control de Stock Estricto: Validación cruzada con el inventario almacenado en Local Storage para impedir que se agreguen más unidades de las disponibles.
6. Flujo de Checkout (Extra): 
   * Vista de facturacion.html para la carga de datos del cliente y método de pago ficticio.
   * Verificación final de stock antes de confirmar la compra.
   * Redirección a compra_lista.html con mensaje de éxito, limpieza de carrito y descuento real del inventario.
